Naming convention

CAMPAIGN_CUE_LENGTH_ROLE_VERSION_STATE

  • CAMPAIGN — AURORA
  • CUE — Anthem / Mnemonic
  • LENGTH — 60 / 30 / 15 / 06 / 03 (seconds)
  • ROLE — MASTER / INSTR / BUMPER / VERT
  • VERSION — v1 / v2 / v3
  • STATE — WIP / APPR / FINAL

Every file in this package follows the convention — no “final_final_v2” guesswork, no lost assets at 11pm before air.

v1 — Concept

Direction options to picture & brief. One chosen, the rest parked — before a full production starts.

v2 — Direction Lock

Arrangement & tone agreed. Bounded revision window opens; all cutdowns derive from here.

v3 — FINAL (Approved)

Signed off without reopening the creative conversation. Locked in 3 rounds.
