Both of these open the same prefilled form with the page's link already in it. You glance at it, add a name or a craft if you know one, and save. The link is captured by construction rather than by remembering — which is the rule the roster runs on.

On a computer

Drag this to your bookmarks bar — do not click it here. Then press it while you are on the page where you found someone, and the form opens with their link in it.

＋ Capture to Chordential ← drag me to the bookmarks bar

Clicking it here does nothing on purpose — it only works from the page you are capturing, and pressing it on this page would just save this page.

Or copy the address by hand

On a phone

Make a Shortcut so capture appears in the share sheet, under the button you already press to share a link.

  1. Open Shortcuts → + → Info (ⓘ) → turn on Show in Share Sheet, and set Accepted types to URLs only.
  2. Add the action Text and paste this, exactly:
  3. Add URL Encode with Shortcut Input as its input.
  4. Add Combine Text with the Text and the encoded input, separator None.
  5. Add Open URLs. Name it Capture to Chordential and save.

On Android the same thing is a bookmark with the bookmarklet above, or any share-to-URL app pointed at {{ capture_url }}&url=.

What it does not do

It never sends anything. Capture writes a prospect and stops. Reaching out is a separate press on that creator's own page, and on Reddit and LinkedIn it opens the message written and addressed for you to send yourself — automating those would risk the account, and the rooms are worth more than the keystrokes.
