# Film masters

Archival masters for the front-of-house films. NOT served by the app — the site's
web-encoded legs live in `src/chordential_oia/web/static/public/world/` and are
re-cut from these masters (slice points + encode recipe in the git history of
that directory).

- `campaign-brief-film-4k.mp4` — the Campaign Brief film (brush → brief → paper
  mountains → cardboard orchestra → world folds into the delivery box). One
  continuous 8s take, 3840×2160@24, upscaled from the approved 720p master
  (Higgsfield seedance render, ByteDance 4K upscale, 2026-07-24). Source of
  truth for the homepage legs and any social/trailer cuts.
