# State the marketing skills keep

These files do not exist until a skill writes one. The contact log, the content
calendar and the video log are each written on first use and read on every run
after that — that is how a skill avoids emailing the same person twice or
repeating a topic it covered last week.

They are committed deliberately. In a cloud session the container is new every
time and only the repository survives, so state kept anywhere else is state that
resets without telling you.
