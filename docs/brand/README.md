# docs/brand

The strategic foundation of the **Chordential** brand — the studio the market hires, as
distinct from **ChordOS**, the operating system it runs on (`docs/architecture/`).

- **`BRAND_FOUNDATION.md`** — start here. Who Chordential is, derived in five stages
  (analysis → prosecution → reconstruction → pillars → manifesto), plus the operating
  rules a marketing team needs to work without the founder: the tests, the fixed
  vocabulary, the banned lines, the proof hierarchy, and decision rights.

Layering: `docs/architecture/CONSTITUTION.md` (what the company *is*) wins over this
folder; this folder wins over every marketing, sales, design, product-copy, and hiring
artefact. `docs/cmo-positioning-brief.md` positions the *software* for Phase B and does
not govern the studio's brand.
